TapePhono · 사용 안내

버전 1.3.5 이상　최종 업데이트: 2026년 11월 6일

첫 테이프 가져오기부터 재생, 면 전환, 음질 조절, Apple Watch 원격 조작까지 실제 사용 순서대로 안내합니다. TapePhono는 로컬 테이프 라이브러리 중심의 가상 데크이며 계정이 필요 없고 오디오는 기본적으로 기기에서 처리됩니다.

1. 시작하기 전에

  • TapePhono는 ‘가상 카세트 데크’입니다. 로컬 오디오 폴더를 테이프로 가져와 실제 데크처럼 장착·재생·전환·조절합니다. 음악을 대신 내려받거나 원본 파일을 수정하지 않습니다.
  • 앨범을 하나의 폴더로 정리하고 파일 앱에서 모든 곡이 재생되는지 확인하세요. 폴더가 정돈될수록 장착 후 곡 순서가 기대와 잘 맞습니다.

2. 첫 테이프 가져오기

  • 데크에서 TAPE BOX / 테이프 베이를 엽니다.
  • ‘폴더 장착’을 선택하고 시스템 파일 선택기에서 앨범 폴더를 고른 뒤 접근을 허용합니다.
  • 앱이 오디오 파일을 읽어 테이프 하나를 만들고 자동으로 A/B 면으로 나눕니다.
  • 한두 곡만 추가하려면 ‘파일 추가’를 선택합니다. 여러 곡을 골라도 하나의 테이프가 됩니다.

3. 라이브러리와 CoverFlow

  • 가운데가 선택된 테이프이고 양옆이 이웃 테이프입니다. 좌우로 밀어 탐색하고, 옆 표지를 클릭해 선택한 뒤 가운데 표지나 ‘장착’을 눌러 데크에 넣습니다.
  • 정렬 버튼으로 추가 날짜/앨범/아티스트 순서를 바꿉니다. 마우스 오른쪽 버튼(macOS) 또는 길게 누르기(iOS/iPadOS)로 표지 변경, 진행 초기화, 삭제, 정보 보기를 할 수 있습니다.

4. 장착과 재생

  • 테이프를 장착해도 자동으로 재생되지 않습니다. 실제 데크와 같습니다.
  • 재생 ▶: 현재 위치에서 시작하며 다시 누르면 재생/일시정지가 전환됩니다.
  • 정지 ■: 정지하고 위치를 유지합니다.
  • 되감기 ◀◀ / 빨리 감기 ▶▶: 짧게 눌러 이동하고 길게 누르면 빠르게 탐색하며 놓으면 돌아옵니다.
  • 릴 두께는 진행에 따라 변합니다. A면은 두꺼워지고 B면은 얇아집니다.

5. 면 전환, 배출, 자동 반전

  • 왼쪽 A/B 레버로 면을 바꿉니다. 수동 전환 시 재생 위치가 반대 면의 대응 위치로 이동합니다.
  • EJECT / 배출은 재생을 멈추고 테이프 베이를 열어 다른 테이프를 고르게 합니다. 진행 상황은 저장됩니다.
  • 설정에서 ‘자동 반전’을 켜면 A면 끝에서 B면으로 자동 전환됩니다. B면 끝은 반복/정지 설정을 따릅니다. 전환 중 짧은 무음은 정상입니다.

6. 스티커와 트랙 목록

  • 스티커에는 앨범, 아티스트, 면, 트랙 번호, 바코드가 표시됩니다. Type-I/II/III는 외형만 바꾸며 소리에는 영향을 주지 않습니다.
  • 스티커를 두 번 클릭하면 기본 스티커와 현재 면의 트랙 목록이 전환됩니다. 두 열로 왼쪽에서 오른쪽으로 배치되며 A/B 면마다 01부터 번호가 붙습니다. 한 페이지에 다 안 들어가면 위아래로 밀어 넘깁니다.
  • 곡 파일이 이동/삭제되었거나 외장 디스크가 연결되지 않으면 목록에는 남지만 재생 시 사용할 수 없다고 표시됩니다.

7. 볼륨, 효과, 프리셋

  • 오른쪽 VOLUME 노브로 출력 볼륨을 조절합니다. 드래그하는 동안 따라오고 놓으면 시스템 볼륨과 화면 표시가 일치합니다. 오디오 파일은 바뀌지 않습니다.
  • 퓨어 출력: 원음을 최대한 유지하고 테이프 색을 줄입니다.
  • 효과: 테이프 노이즈, 와우/플러터, 공간감의 강도를 조절합니다.
  • PRESET 노브로 ‘TapePhono HQ’, ‘TapePhono Classic’ 등 내장 스타일을 고르고 BASS 노브로 저역 두께를 조절합니다. 모든 조정은 재생에만 적용됩니다.

8. 카운터, 메모리 루프

  • 카운터는 현재 위치를 표시합니다. ‘리셋’은 카운터만 0으로 만들고 오디오 파일은 건드리지 않습니다.
  • 메모리 루프: 시작과 끝을 표시해 그 구간을 반복합니다. 다시 끄면 해제되며 테이프 교체, 배출, 앱 종료 시 상태에 따라 해제됩니다.

9. Apple Watch 리모컨

  • iPhone에 TapePhono를 설치하면 페어링된 Apple Watch에 워치 앱이 자동 설치됩니다. 재생, 정지, 빨리 감기, 되감기, 면 전환, 볼륨을 조작할 수 있습니다.
  • 디지털 크라운을 돌려 볼륨을 조절하고 화면 키로 재생을 제어합니다.
  • 시계 페이스에 TapePhono 컴플리케이션/위젯을 추가할 수 있습니다.
  • 블루투스 또는 Wi-Fi 연결을 유지하세요. 연결이 끊기면 시계는 마지막으로 알려진 상태를 표시합니다.

10. 설정과 화면

  • 테마/외형: 웜 화이트, 스톤, 그래파이트 중 선택하거나 시스템 밝기에 따릅니다.
  • 언어: 중국어 간체/번체, English, 日本語, Español, Français, Deutsch, 한국어.
  • 스티커: Type-I/II/III.
  • 피드백: 설정에서 문제나 제안을 보낼 수 있으며 이메일은 선택 사항입니다.
  • 개인정보 처리방침/사용 안내: 온라인 문서를 엽니다. 오프라인에서도 앱은 사용할 수 있습니다.

11. 파일, 백업, 복원

  • 원본 오디오는 선택한 위치에 그대로 남습니다. TapePhono는 라이브러리 구조, 진행 상황, 설정, 표지 캐시만 저장하며 앱을 삭제하면 보통 이 로컬 상태가 사라집니다.
  • ‘백업’은 라이브러리 구조와 진행 상황을 내보냅니다. 오디오 파일은 포함되지 않습니다.
  • ‘복원’은 확인 후 백업을 가져옵니다. 복원 후 원본 파일이 원래 위치에 있는지 확인하세요.
  • 앨범 폴더를 옮기면 기존 테이프에 파일 없음이 표시됩니다. 원래 위치로 되돌리거나 다시 가져오세요.

12. 자주 묻는 질문

  • 소리가 없음: 무음, 볼륨, 재생 상태, 블루투스 출력을 확인하세요.
  • 표지가 없음: 파일에 내장 아트가 없고 폴더에도 이미지가 없는 경우입니다. 직접 지정하거나 이미지를 넣고 다시 가져오세요.
  • 파일을 사용할 수 없음: 원본이 이동/삭제되었거나 외장/iCloud 파일이 다운로드되지 않은 경우입니다.
  • 면 전환 후 재생 안 됨: 수동 전환은 정지 상태를 유지합니다. 재생 키를 누르세요.
  • Apple Watch가 반응하지 않음: 페어링과 설치를 확인하고 iPhone에서 앱을 한 번 연 뒤 필요하면 양쪽 앱을 재시작하세요.

13. 빠른 참조

  • 가운데 표지/장착: 선택한 테이프를 데크에 넣기.
  • CoverFlow 좌우 밀기: 테이프 탐색.
  • 스티커 두 번 클릭: 기본 스티커/트랙 목록.
  • 빨리 감기/되감기 길게: 빠른 탐색.
  • A/B 레버: 면 전환.
  • EJECT: 정지 후 베이 열기.
  • VOLUME: 출력 볼륨, PRESET: 내장 음색.
  • 이 안내는 사용법만 설명하며 내부 오디오 처리나 구현 세부 정보는 다루지 않습니다.

14. 무료 버전과 Pro

  • 무료 버전에서는 최대 5개 앨범(총 5시간 또는 80곡)을 가져올 수 있으며, 첫 가져오기 전에 한도를 안내합니다.
  • 무료 버전에서도 모든 기본 프리셋과 프리 EQ를 사용할 수 있습니다. 잠긴 파라미터는 프리셋 값만 표시되며 수동으로 조정할 수 없습니다.
  • Pro는 구독이 아닌 1회 구매입니다. 무제한 테이프 라이브러리, 전체 튜닝 파라미터, 고스트 트랙 제어, 사용자 프리셋 가져오기/내보내기가 잠금 해제됩니다.
  • 구매는 App Store에서 처리됩니다. 설정의 구매 복원을 사용할 수 있으며, 구매 후 메인 화면에는 업그레이드 표시가 나타나지 않습니다.

TapePhono 操作说明

适用版本：1.3.5 及后续版本　最后更新：2026 年 11 月 7 日

从导入第一盘磁带，到播放、翻面、调音与手表遥控——这是一份按实际使用顺序编写的说明。TapePhono 以本地磁带库为核心，不需要注册账号，音频默认只在你的设备上处理。

1. 开始之前

TapePhono 是一台“虚拟卡座”：你把本地音频文件夹导入成一盘盘磁带，然后像使用真实卡座一样装带、播放、翻面、调音。它不会替你下载音乐，也不会修改原始音频文件。

  • 系统要求：iOS / iPadOS 17 或更高、macOS 14 或更高；Apple Watch 端需与 iPhone 配对使用。
  • 音频来源：请先将音乐文件保存到“文件”App、iCloud Drive、外接磁盘或电脑上的文件夹。
  • 不需要账号：没有登录、订阅或云端曲库；你的磁带库保存在本机。
  • 首次启动：应用会显示一台空卡座与空磁带库，按第 2 节导入即可。
建议先在“文件”App 中把一张专辑整理成一个文件夹，并确认每首歌都能正常播放。TapePhono 会按文件名顺序把这一面分成 A/B 两面；文件夹越规整，装带后的曲序越接近你的预期。

2. 导入你的第一盘磁带

2.1 从文件夹导入（推荐）

  1. 在卡座界面找到 TAPE BOX / 磁带仓，打开磁带库。
  2. 点击 “装入文件夹 / LOAD A FOLDER”（不同设备上的措辞可能是“导入文件夹”“添加文件夹”）。
  3. 在系统文件选择器中选中一张专辑文件夹，确认授权。
  4. 应用会读取其中的音频文件，按顺序生成一盘磁带，并自动分成 A、B 两面。
  5. 导入完成后，CoverFlow 中会出现这张磁带的封面卡片；没有内嵌封面时，会使用文件夹中的封面图或程序化贴纸。

2.2 从单个文件导入

如果只想添加一两首，可选择 “添加文件 / CHOOSE FILES”，再选中音频文件。多选时同样会生成一盘磁带。

2.3 导入时会自动完成的事

  • 读取曲名、专辑、歌手、时长与封面；没有标签时使用文件名。
  • 按文件夹中的自然顺序排列曲目，并把整盘带分成 A/B 两面。
  • 为两面各加入一小段引带/尾带，留出装带与翻面的机械时间。
  • 在本地建立磁带库条目，记住文件位置，方便下次直接装带。

2.4 导入失败或歌曲缺失

  • 确认文件格式受支持：FLAC、WAV、AIFF、MP3、M4A、CAF 等常见格式。
  • 确认文件没有损坏，且“文件”App 中可以正常播放。
  • 如果文件在导入后被移动、重命名或所在磁盘未挂载，装带时该曲目会显示为不可用；请重新导入或把文件放回原位置。

3. 磁带库与 CoverFlow

磁带库以 CoverFlow 的形式展示：中央是当前选中的磁带，左右两侧是相邻磁带。封面可以是你导入时读取的内嵌封面，也可以是自定义图片。

3.1 浏览与选择

  • 左右滑动 / 触控板横扫：在封面之间移动。
  • 单击侧边封面：选中该磁带，中央卡片会切换过去。
  • 单击中央封面（或“装入”）：把选中的磁带装进卡座。
  • 滚动排序：使用排序按钮可在“添加日期 / 专辑名 / 歌手”等顺序之间切换。

3.2 封面与标签

  • 右键（macOS）或长按（iOS / iPadOS）封面可打开操作菜单。
  • 可更换封面、重置播放进度、删除磁带或查看磁带信息。
  • “重置进度”只清空这盘带的播放位置记录，不会删除音频文件。

3.3 空库状态

第一次打开时 CoverFlow 为空，这是正常的。导入至少一张专辑后，卡片就会出现；如果刚删除了全部磁带，也会回到空库状态。

4. 装带与播放

4.1 装带

选中磁带后点击中央封面或“装入”。装带完成后，卡座会显示这盘带的贴纸与带盘厚度，但不会自动开始播放——这是刻意的，和真实卡座一致。

4.2 四个走带键

按键作用
播放 ▶从当前位置开始播放；再按一次可在播放与暂停之间切换（以界面状态为准）。
停止 ■停止走带，保留当前位置；再次播放从停止处继续。
快退 ◀◀短按向后快速走带；长按可加速搜索，松开后回到正常状态。
快进 ▶▶短按向前快速走带；长按可加速搜索；到带尾会自动停住。

4.3 播放中的界面反馈

  • 带盘厚度随播放进度变化：A 面越播越厚，B 面越播越薄。
  • 码表显示当前位置；磁带贴纸显示当前面与曲序。
  • 暂停、停止、快进、快退时，按键灯与状态屏会同步变化。
  • 播放到带尾时，按设置可能自动停止、自动翻面或循环。

4.4 从指定曲目开始

在贴纸曲目列表（见第 6 节）中点击某一首，可直接跳到该曲目；也可以先停止，再用快进/快退找到大致位置，然后按播放。

5. 翻面、退带与自动翻面

5.1 手动翻面

卡座左侧的 A/B 拨杆用于换面。翻面后，播放位置会切换到另一面的对应位置；如果当前是停止状态，翻面后仍保持停止，需手动按播放。

5.2 退带 / 开仓

EJECT / 弹出会停止走带并打开磁带仓，让你选择另一盘磁带。退带会保存当前进度；下次装入同一盘带时会回到上次位置（除非你重置了进度）。

5.3 自动翻面

在设置中开启“自动翻面”后，A 面播放到带尾会自动翻到 B 面继续；B 面到带尾则按你的“循环 / 停止”设置处理。关闭自动翻面时，到带尾会停下。

自动翻面需要一点机械时间，期间会短暂静音，这是正常现象；不要在此期间连续按播放/停止，以免打断翻面流程。

6. 贴纸与曲目列表

6.1 默认贴纸

磁带窗右侧的贴纸显示专辑名、歌手、面标、曲序与条码。你可以在设置中切换 Type-I / Type-II / Type-III 三种贴纸版式；版式只影响外观，不影响声音。

6.2 曲目列表

  • 双击贴纸区域：在默认贴纸与本面曲目列表之间切换。
  • 曲目列表按两列、从左到右排列，并带有本面序号（A 面与 B 面各自从 01 开始）。
  • 一页放不下时，上下滑动翻页；翻页不会改变磁带或播放状态。
  • 再次双击可回到默认贴纸。

6.3 曲目不可用

如果某首曲目的源文件被移动、删除或所在磁盘未连接，列表中仍会保留该曲目，但播放时会提示不可用。把文件放回原位置，或重新导入这张专辑即可恢复。

7. 音量、音效与预设

7.1 音量旋钮

右侧的 VOLUME 旋钮控制输出音量。拖动时指针跟手；松开后，系统音量与界面显示会保持一致。它直接调整设备输出音量，不会改变音频文件本身。

7.2 纯净输出与音效

  • 纯净输出：尽量保留源文件原貌，减少磁带染色；适合校准或对比。
  • 整盘循环：到带尾后从本面开头继续，适合背景音乐。
  • 音效设置：调整磁带噪声、抖动、空间感等“卡座味道”的强弱。喜欢干净声音时可将音效调低。

7.3 预设与重低音

  • 预设旋钮：在“TapePhono HQ”“TapePhono经典”等内置风格之间切换；不同预设对应不同的音色取向。
  • 重低音旋钮：调整低频厚度；建议从小幅度开始，避免掩盖中频细节。
  • 所有调整只影响播放时的声音，不会改写你的音频文件。

7.4 推荐起点

第一次使用时，可以先用“TapePhono HQ”预设、纯净输出关闭、音效适中；确认一切正常后，再尝试“TapePhono经典”或更强的染色。

8. 码表、重复与记忆循环

  • 码表：显示当前播放位置；“复位”只把码表归零，不改变音频文件。
  • 重复：开启后，当前面到带尾会回到本面开头继续播放。
  • 记忆循环：用于反复练习或对比某一段。按界面提示标记起点与终点，即可在这一段内循环；再次关闭可退出循环。
  • 换带、退带或关闭应用后，记忆循环会按界面状态解除。

9. Apple Watch 遥控

在 iPhone 上安装 TapePhono 后，配对的 Apple Watch 会自动安装手表端应用。手表可以远程控制播放、停止、快进、快退、翻面与音量。

  • 表冠：旋转可调整音量。
  • 屏幕按键：播放 / 停止 / 快进 / 快退；具体布局以手表屏幕为准。
  • 复杂功能 / 小组件：可在表盘添加 TapePhono 快捷入口；点击可打开手表端应用。
  • 手表与 iPhone 需保持蓝牙或 Wi-Fi 连接；连接断开时，手表会显示最后已知状态。

10. 设置与外观

  • 主题 / 外观：在暖白、岩石灰、石墨黑之间切换；也可让应用跟随系统亮暗。
  • 语言：支持简体中文、繁体中文、English、日本語、Español、Français、Deutsch、한국어。
  • 贴纸版式：Type-I / Type-II / Type-III 三种视觉风格。
  • 反馈与建议：通过设置页提交问题或建议；邮箱可选填。
  • 隐私政策 / 用户手册：打开在线文档；离线时仍可正常使用应用，只是无法打开网页。

11. 文件、备份与恢复

11.1 文件保存在哪里

原始音频始终留在你选择的位置；TapePhono 只保存磁带库结构、播放进度、设置与封面缓存。删除应用通常会清除这些本地状态，请提前备份。

11.2 备份磁带库

在磁带库的菜单中使用 “备份 / Backup”，选择一个保存位置，应用会导出备份文件。备份包含磁带库结构与进度信息；音频文件本身不包含在备份中，需要另行保留。

11.3 恢复

使用 “恢复 / Restore” 选择备份文件。恢复前会要求确认；恢复后请检查每盘磁带的源文件是否仍在原位置。

11.4 移动或重命名文件

如果移动了专辑文件夹，旧磁带会提示文件不可用。把文件夹放回原路径，或重新导入新位置；不要只修改单个文件名，否则曲序与进度可能对不上。

12. 常见问题

没有声音

  • 确认设备没有静音，音量旋钮没有在 0%。
  • 确认当前是“播放”状态，而不是暂停或停止。
  • 检查音频输出是否被蓝牙耳机 / 外接设备接管。

导入后没有封面

音频文件本身没有内嵌封面，且文件夹中也没有封面图。可以右键 / 长按封面手动更换，或把一张 JPG/PNG 放入专辑文件夹后重新导入。

磁带显示“文件不可用”

源文件被移动、重命名、删除，或所在外接磁盘 / iCloud 文件尚未下载。请恢复原路径或重新导入。

翻面后没有自动播放

手动翻面默认保持停止状态；按播放键继续。若开启了自动翻面，到带尾会自动换面并继续。

Apple Watch 不显示或无法控制

  • 确认手表已与 iPhone 配对，且两端应用都已安装。
  • 打开 iPhone 上的 TapePhono，让应用在前台完成一次连接。
  • 检查蓝牙 / Wi-Fi 是否开启；必要时重启两端应用。

播放到带尾直接停止

这是“到带尾停止”的正常行为。若希望继续，可开启自动翻面或整盘循环。

14. 免费版与 Pro

  • 免费版最多可导入 5 张专辑（累计 5 小时或 80 首曲目）；首次导入前会提示该限制。
  • 免费版可使用全部原厂预设与前置均衡；锁定的参数仅显示预设数值，不能手动调节。
  • Pro 为一次性买断，不是订阅；解锁无限磁带库容量、完整深度调音参数、幽灵音轨控制与自定义预设导入/导出。
  • 购买由 App Store 处理；可在「配置管理」页恢复购买。购买后主界面不再显示升级标识。

TapePhono User Guide (English)

Applies to: version 1.3.5 and later　Last updated: November 7, 2026

TapePhono is a virtual cassette deck built around a local tape library. No account is required, and your audio is processed on your device by default. This guide follows the real workflow: import, load, play, flip, adjust and control from Apple Watch.

1. Before you start

  • Requirements: iOS/iPadOS 17+, macOS 14+; the watch app requires a paired iPhone.
  • Audio source: keep your music in the Files app, iCloud Drive, an external disk or a computer folder.
  • No account: there is no sign-in, subscription or cloud library; your library stays on this device.

For best results, organize one album per folder and make sure every track plays correctly in Files. TapePhono will split the folder into side A and side B in file-name order.

2. Import your first tape

  1. Open TAPE BOX from the deck.
  2. Choose “LOAD A FOLDER” (or “Add Folder”).
  3. Pick the album folder in the system file picker and confirm access.
  4. The app reads the audio files, creates one tape and splits it into sides A and B.
  5. The tape appears in CoverFlow. If there is no embedded artwork, a folder image or a generated sticker is used.

You can also choose “CHOOSE FILES” to add individual tracks. Imported tapes keep their original files in place; TapePhono only stores library metadata, progress, settings and cover thumbnails.

3. Library and CoverFlow

  • Swipe or scroll horizontally to browse tapes; click a side cover to select it.
  • Click the center cover or “Load” to put that tape in the deck.
  • Use the sort button to order by date added, album or artist.
  • Right-click (macOS) or long-press (iOS/iPadOS) a cover to change artwork, reset progress, delete a tape or view info. “Reset progress” never deletes audio files.

4. Loading and playback

Loading a tape does not start playback automatically—just like a real deck. Use the four transport keys:

KeyAction
Play ▶Start from the current position; press again to pause/resume.
Stop ■Stop and keep the position.
Rewind ◀◀Short press to rewind; hold to search faster.
Fast-forward ▶▶Short press to wind; hold to search faster; stops at the end.

Reel thickness changes with progress (side A fills up, side B empties). The counter and sticker follow the current side and track. To start from a specific track, open the track list (section 6) and tap it.

5. Flipping, ejecting and auto-reverse

  • The A/B lever flips the tape. Manual flips keep the stopped/playing state as shown on screen.
  • EJECT stops the transport and opens the tape bay; progress is saved for next time.
  • With auto-reverse enabled, side A automatically flips to side B at the end; side B follows your loop/stop setting. A short mechanical pause and mute during the flip is normal.

6. Sticker and track list

The sticker shows album, artist, side, track number and barcode. Type-I/II/III change only the look, not the sound.

  • Double-click the sticker to switch between the default sticker and the current side’s track list.
  • Tracks are shown in two columns with side-local numbers; A and B each start at 01.
  • Swipe up/down to change pages; paging never changes playback.

7. Volume, effects and presets

  • VOLUME adjusts the output volume and follows your drag; it does not alter your audio files.
  • Pure output keeps the source clean; whole-tape loop repeats the current side; effects control tape noise, wow/flutter and space.
  • PRESET selects built-in styles such as “TapePhono HQ” and “TapePhono Classic”; BASS adds low-end weight.
  • Recommended starting point: TapePhono HQ, pure output off, moderate effects.

8. Counter, repeat and memory loop

  • Counter shows the current position; Reset only zeroes the counter.
  • Repeat returns to the start of the current side at the tape end.
  • Memory loop marks a start and end point for repeated practice; closing or ejecting ends the loop.

9. Apple Watch remote

The watch app is installed with the iPhone app and can control play, stop, fast-forward, rewind, side and volume.

  • Rotate the Digital Crown to adjust volume.
  • Use the on-screen keys for transport control.
  • Add TapePhono as a complication/widget on your watch face for quick access.
  • Keep Bluetooth or Wi-Fi connected; when disconnected, the watch shows the last known state.

10. Settings and appearance

  • Theme: warm white, stone or graphite; or follow the system appearance.
  • Languages: Simplified/Traditional Chinese, English, Japanese, Spanish, French, German, Korean.
  • Sticker style: Type-I / II / III.
  • Feedback, privacy policy and this guide are available from Settings.

11. Files, backup and restore

Original audio stays where you put it. TapePhono stores library structure, progress, settings and cover thumbnails locally; deleting the app usually removes this local state.

  • Backup exports the library structure and progress. Audio files are not included—keep them separately.
  • Restore imports a backup after confirmation. Check that source files are still in their original locations.
  • If you move an album folder, old tapes will report unavailable files; put the folder back or re-import it.

12. Troubleshooting

  • No sound: check mute, volume, play state and Bluetooth/output routing.
  • No artwork: the file has no embedded art and the folder has no cover image; add one or set artwork manually.
  • Files unavailable: the source was moved/deleted, or an external/iCloud file is not downloaded; restore the path or re-import.
  • Watch not responding: confirm pairing and installation, open the iPhone app once, check Bluetooth/Wi-Fi, then restart both apps.
  • Stops at the end: normal end-of-tape behavior; enable auto-reverse or loop to continue.

14. Free Edition and Pro

  • The Free edition supports up to 5 albums (5 hours or 80 tracks total); a notice appears before the first import.
  • All factory presets and Pre-EQ are available in Free. Locked parameters display preset values and cannot be adjusted manually.
  • Pro is a one-time purchase, not a subscription. It unlocks unlimited library capacity, full tuning parameters, Ghost Track controls and custom preset import/export.
  • Purchases are processed by the App Store. Use Restore Purchases in Config; after purchase, no upgrade badge is shown on the main screen.

This guide describes usage only and does not disclose internal audio-processing details. If the on-screen text differs slightly, the current app version is authoritative.
